# EcoCompost - Wet Waste Collection & Vermicompost Platform

A complete full-stack web application for wet waste collection and vermicompost sales with multilingual support (English, Hindi, Marathi).

## Features

- 🌍 **Multilingual Support**: English, Hindi, and Marathi
- 🔐 **Authentication**: Secure user login and signup
- 📦 **Waste Pickup Booking**: Schedule wet waste collection
- 🛒 **Vermicompost Shop**: Order organic compost online
- 👨‍💼 **Admin Dashboard**: Manage pickups, orders, and MongoDB configuration
- 🎨 **Beautiful UI**: Modern, responsive design with green eco-friendly theme


## What technologies are used for this project?

This project is built with:

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
